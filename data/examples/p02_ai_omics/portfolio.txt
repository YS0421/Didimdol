포트폴리오 (4학년, 가상 인물 p02_ai_omics)

■ 머신러닝 수업 프로젝트 (2025.09-2025.12) - 팀장
공개 유전자 발현 데이터로 암 아형 분류 모델을 Python과 scikit-learn으로 직접 설계하고 학습시켰다. 기계학습 모델의 성능을 교차검증으로 비교했다.
사용 도구: Python, scikit-learn, pandas
결과: 기말 발표

■ 바이오인포매틱스 온라인 강의
유전체분석과 오믹스 데이터 처리 기초를 온라인 강의로 공부했다.
사용 도구: R

■ 헬스케어 데이터 분석 공모전 (2026.07-2026.08) - 데이터 분석 담당
의료 데이터 전처리와 시각화를 맡아 Python으로 분석 파이프라인을 만들었다. 팀 보고서의 데이터 분석 파트를 작성했다.
사용 도구: Python, matplotlib
결과: 장려상

■ 생명정보학 미니 프로젝트
공개 RNA-seq 데이터로 차등발현 유전자 분석을 스스로 기획해 수행하고 결과를 블로그에 정리했다.
사용 도구: Python, DESeq2
배운 점: 오믹스 데이터 정규화가 결과를 크게 바꾼다.
